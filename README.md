# Odin Recipes

The purpose of this project is to practice foundational skills in writing html
files, with the added benefit of sharing a few delicious recipes with my fellow
Odin Project students.

## Skills Demonstrated

- Implement html boilerplate to establish basic structure of webpages.
- Add text using headings, paragraphs, and lists to communicate the recipes in 
an organized manner.
- Insert links to allow visitors to easily navigate between webpages.
- Insert images from the Wikipedia Commons with proper attribution.
